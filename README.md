 House Prices – Exploratory Data Analysis (EDA)

📌 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on a House Prices dataset using Python. The main objective is to understand the dataset, identify important factors affecting house prices, analyze relationships between variables, detect outliers, and discover meaningful insights through statistical analysis and data visualization.

🎯 Project Objectives

* Understand the structure and characteristics of the dataset.
* Perform data cleaning and preprocessing.
* Identify numerical, categorical, and ordinal variables.
* Handle missing values and duplicate records.
* Perform descriptive and statistical analysis.
* Analyze house price distributions.
* Study correlations between different features.
* Detect and visualize outliers.
* Generate meaningful insights using graphs and statistical techniques.

🛠️ Technologies & Libraries Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* SciPy
* Jupyter Notebook
